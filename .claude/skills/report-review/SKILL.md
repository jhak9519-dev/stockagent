# StockAgent 리포트 품질 검토

`output/<날짜>/` 의 최신 리포트를 아래 순서로 검토하고, 결과를 표로 정리해 보고한다.
사용자에게 팩트만 간략히 전달되도록 하며, 풀어쓰지 않고 핵심만 요약한다. (불필요한 서술어 지양)
각 판정의 이유를 초심자도 이해할 수 있게 근거를 들어 설명한다.

## 1. 텍스트 확보
- **HTML 원본 우선** (PDF와 같은 이름의 `.html`, 2026-07-16부터 동시 저장).
- HTML이 없는 옛 리포트는 `.venv`의 pypdf로 추출: `PdfReader(경로).pages[i].extract_text()`.
- 이 환경은 poppler가 없어 Read 도구로 PDF 페이지 렌더 불가. PowerShell 실행 시 `$env:PYTHONIOENCODING='utf-8'`.

## 2. 수치 검산 (계산기로 직접)
- PER = 현재가 ÷ EPS, 상승여력 = 목표가/현재가 − 1 (±0.1%p 이내)
- **목표주가 산출식**: "EPS(또는 BPS) × 타깃 배수 = 목표가"가 표기·계산 일치하는지
- **매수 구간(지지선 기반)**: 상승추세=상단 20일선·하단 60일선(−10% 제한), 조정 중=현재가 −1%~−7%. **상단은 반드시 현재가보다 낮아야 함**(현재가 추격매수 금지, 사용자 확정 2026-07-16)
- 손절가 = 매수 구간 하단 × 0.95
- **시나리오 표**: 강세/기본/약세 3개, **확률 합 = 100%**, base 가격 = 확정 목표가. 기대값 = Σ(가격×확률).
- **리스크/리워드** = (목표가−매수중심)/(매수중심−손절). 양수 확인.
- 재무비율(영업이익률·순이익률·부채비율) 재무제표로 역산. **현금흐름 행**(영업CF·FCF): KR=영업CF만(FCF N/A 정상), US=둘 다.
- PBR·시총은 실시간 지표와 연간 재무 역산이 수 % 어긋날 수 있음(소스 시점차) — 오류 아님.

## 3. 차트 분석·수급 섹션
- "차트 분석 · 기술적 전망": 지표 표(추세강도 n/10·이동평균 배열·볼린저 %b·일목균형표·RSI·MACD) + **지지선/저항선 행** + AI 전망 서술. AI 전망이 지표 신호와 모순되면 지적.
- **수급 동향 일별 표(최근 7거래일, 부호색: 상승/순매수 빨강·하락/순매도 파랑)**:
  - KR = 종가·등락률 + 개인/외국인/기관 순매수(억원) + 외국인 보유율 + **연기금**(judal.co.kr, "목록에 없음"도 정상)
  - US = 종가·등락률 + **거래량** + 기관/내부자 보유·공매도 (미국은 투자자별 매매 미공개 → 데이터 한계, 누락 아님)
- 주가 차트에 볼린저밴드 음영 표시.

## 4. 논리 일관성
- 투자의견 ↔ 목표가 방향 ↔ 컨센서스 ↔ 기술적 신호가 한 방향인지
- **매매전략(추세 기반, AI 판단)**: 종목마다 새로 서술돼야 함(획일적 "50/30/20 눌림목" 반복이면 편향 재발 — 사용자 지적사항). 추세강도 7↑=추세추종/4~6=긍정·부정 시나리오/3↓=관망. AI 실패 시 `context.trade_strategy` 규칙기반 폴백.
- 급등주(3개월 +50%↑ & 52주 고점 90%↑)는 **과열 배지**가 리포트·카톡에 떠야 함
- 대화체·면책·제안("~해드릴까요") 유입 여부(claude_code guard). "규칙 기반 자동 요약" 있으면 AI 폴백 발생 → 원인(CLI 인증/한도) 확인.

## 5. 가독성·레이아웃 (사용자 선호)
- 핵심 수치·결론이 `<b>` 강조(빨강)로 — AI `**…**` 마킹, 문단당 1~3곳(4곳↑ 남발이면 지적)
- 분량: 프롬프트 글자수 준수(시황 body~550·재무~400·요약~350), 문장 자연 종료(중간 절단 없어야)
- 헤더: 시세 기준일·선정 근거·자동발굴 점수·**발굴 배지(누적 N회·M회 연속, 2회+)**·**매수가 대비 수익률 배지**, US는 실적 발표 예정일
- **웹 발행본(다크)**: 주제별 블록 카드, 넉넉한 여백, 핵심 포인트 키워드 칩
- **PDF 페이지**: 자연 흐름(짧은 섹션 합치고 넘치면 새 페이지), 표·차트 경계에서 안 잘림

## 6. 발송·수익률 교차 확인 (해당 시)
- **카톡 = 1건**(2026-07-21 확정, 이전 2건에서 변경): 오늘의 종목·의견·목표가(%)·매수구간·손절 + 경고(과열/폴백) + "상세 분석 → [리포트 보기]" 버튼. 줄바꿈으로 항목별 정리. `**` 마커가 카톡에 노출되면 `notify._split_sentences` 제거 로직 확인.
- **이메일**: 요약 본문 + PDF 첨부(네이버 SMTP). 매수구간 상단이 현재가와 같으면 버그(trade_zone 확인).
- **웹 수익률**: 목록 상단 주간·월간·전체 평균 + 카드/상세 "매수가 대비 +X.X%"(수익 빨강/손실 파랑). 매수가 = 구간 중심값, 배치마다 현재가로 갱신.
